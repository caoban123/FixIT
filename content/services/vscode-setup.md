### Bạn sẽ nhận được
- VS Code cài đặt sạch, giao diện dễ nhìn
- Extension đúng ngôn ngữ bạn học (Python, C/C++, Markdown…)
- Tự động format, gợi ý code, phím tắt cần nhất
- Terminal tích hợp chạy ngay trong VS Code

### Phù hợp khi
- VS Code không nhận ngôn ngữ, không chạy được code
- Chưa biết nên cài extension nào
