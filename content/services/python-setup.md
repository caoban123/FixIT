### Bạn sẽ nhận được
- Python + pip hoạt động đúng, thêm vào PATH
- Virtual environment mẫu để bạn làm theo cho các dự án sau
- VS Code nhận đúng Python interpreter
- Chạy thử một chương trình mẫu để chắc chắn mọi thứ ổn

### Phù hợp khi
- Gõ `python` báo lỗi hoặc mở Microsoft Store
- `pip install` không chạy hoặc báo lỗi quyền
- Lỗi virtual environment, thư viện cài rồi mà vẫn "No module named…"
