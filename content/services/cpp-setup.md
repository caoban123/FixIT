### Bạn sẽ nhận được
- Compiler (g++/gcc) cài đúng và đã thêm vào PATH
- VS Code + extension C/C++ cấu hình sẵn
- Cấu hình build và chạy bằng một phím
- Một project mẫu để bạn bắt đầu bài tập

### Phù hợp khi
- Báo lỗi `g++ is not recognized`
- VS Code không biên dịch hoặc không debug được
- Mới học Lập trình cơ sở và cần môi trường chuẩn
